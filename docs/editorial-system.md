# Personal newspaper: разделение ответственности

Этот документ не задаёт стиль газеты. Он фиксирует границы между техническим
контуром TairaSearch и редакционной работой AI-агента.

## Что делает Python

Python читает профиль, выполняет поиск по SQLite, готовит контекст кандидатов и
сравнения с журналом, валидирует публикационный манифест, синхронизирует запись
в `used_finds.csv` и рендерит сохранённый текст. Эти механизмы не определяют,
интересна ли история, и не подтверждают доставку результата в чат.

## Что делает AI-агент

Агент проверяет полный контекст источника и спорные совпадения, выбирает
достойные истории и пишет карточки по единственному авторскому заданию:
`examples/codex/daily-news-prompt.md`. При необходимости карточки передаются
независимому читателю по `examples/codex/reader-review.ru.md`.

Исследовательское досье хранит опору утверждений, атрибуцию, решение по
новизне и редакционный выбор. Читательский Markdown не содержит внутренних
путей, ID и служебных объяснений.

## Что остаётся технически обязательным

- источник и контекст проверяются до написания;
- подтверждённые повторы не публикуются, неоднозначные совпадения не выдаются
  за новые находки;
- пробный запуск не меняет журнал;
- точный финальный текст сохраняется в манифесте до регистрации;
- `record-publication` выполняется до `render-publication`;
- регистрация сохраняет блокировку, атомарную запись и идемпотентность;
- восстановление использует прежний манифест без нового поиска и переписывания;
- успешный render не считается подтверждением доставки в пользовательский чат.

Точный порядок команд, ошибки и восстановление описаны в
`examples/codex/research-workflow.md` / `.ru.md` и `docs/ai-workflow.md`.
