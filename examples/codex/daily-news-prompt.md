# Example: daily-news automation

This is a sanitized prompt template, not an active automation configuration.

> Run the deterministic daily candidate command against the configured local
> index. Read the selected chunks and their neighbouring context. Separately
> search scholarship when it adds a useful interpretation. Produce five concise
> historical cards, state whether evidence is primary, literary, or scholarly,
> preserve precise source references, and avoid unsupported claims. After the
> cards have been published successfully, record their stable identifiers so a
> later run does not repeat them. Do not modify retrieval rules or rebuild the
> index during the editorial run.

The release 0.1 hardening work will make the final journal update idempotent.
