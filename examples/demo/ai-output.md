# Example Codex output: five TairaSearch demo cards

> **DEMONSTRATION ONLY.** Every event and excerpt below is fictional test
> material. These cards are not historical claims, and the source-like folder
> names do not mean that the text comes from the named historical works.

## 1. [ДЕМО] Сигэмори и музыкальный вечер в Киото

**Статус:** вымышленный тестовый эпизод, не историческое сведение.

**Что случилось.** В синтетическом многоязычном фрагменте Сигэмори играет на
бива перед небольшим собранием в Киото. Дата внутри фиктивной записи обозначена
как 治承三年.

**Почему это интересно.** Карточка показывает, как поиск связывает имя,
музыкальный термин и место в русско-японском тексте, а ИИ превращает найденный
фрагмент в краткое описание, не добавляя новых фактов.

**Фрагмент.** «Синтетическая русская запись для проверки многоязычного поиска;
это не историческая цитата. 治承三年、平重盛は京都で琵琶を играл перед небольшим
собранием.»

**Источник.** Синтетический файл `吉記/русская_музыка.txt`, классификация
`contemporary_diary` / `historical`, chunk `ch_3b39818e3652f04460690a93`.
Название папки используется только для теста классификации.

## 2. [ДЕМО] Мунэмори на пире в Фукухаре

**Статус:** вымышленный тестовый эпизод, не историческое сведение.

**Что случилось.** Синтетический японский текст говорит, что Мунэмори устроил
пир в Фукухаре и пил вино с гостями. В фиктивном фрагменте указана дата 寿永二年.

**Почему это интересно.** Пример демонстрирует поиск бытовой темы в тексте,
классифицированном как литературный, и сохранение различия между литературным
типом источника и историческим утверждением.

**Фрагмент.** «これは検索試験のための合成文であり、文学作品からの引用ではない。
寿永二年、平宗盛は福原で酒宴を開き、客と宴の酒を酌み交わした。»

**Источник.** Синтетический файл `平家物語/宴.txt`, классификация `war_tale` /
`literary`, chunk `ch_b47aa27981b8a752c47e73f6`. Текст не является
цитатой из «Хэйкэ-моногатари».

## 3. [ДЕМО] Токитада: пленение и ссылка

**Статус:** вымышленный тестовый эпизод, не историческое сведение.

**Что случилось.** В синтетической записи Токитада схвачен в Киото, некоторое
время находится в заключении, а затем отправлен в ссылку. Указанная внутри
фиктивного текста дата — 文治元年.

**Почему это интересно.** Карточка показывает, как локальная близость имени и
терминов плена используется как проверяемое основание для краткого пересказа.

**Фрагмент.** «これは検索試験のための合成文であり、史料からの引用ではない。
文治元年、平時忠は京都で捕らえられ、しばらく囚われた後に配流された。»

**Источник.** Синтетический файл `吾妻鏡/пленение.txt`, классификация
`later_chronicle` / `historical`, chunk `ch_64ad1a8c15358427306b1b1a`.
Текст не взят из «Адзума кагами».

## 4. [ДЕМО] Томомори помогает во время пожара

**Статус:** вымышленный тестовый эпизод, не историческое сведение.

**Что случилось.** Синтетический литературный фрагмент сообщает, что Томомори
узнал о пожаре в Киото и помог человеку покинуть сгоревшую усадьбу. Внутри
фиктивной записи указана дата 治承四年.

**Почему это интересно.** Пример проверяет, может ли система выделить локальный
невоенный сюжет и при этом не выдать литературную классификацию за подтверждение
реального события.

**Фрагмент.** «これは検索試験のための合成文であり、文学作品からの引用ではない。
治承四年、平知盛は京都の火事を知り、焼失した館から人を助けた。»

**Источник.** Синтетический файл `源平盛衰記/пожар.txt`, классификация
`war_tale` / `literary`, chunk `ch_fec810decc8cc4d78773fd36`. Текст не
является цитатой из названного произведения.

## 5. [ДЕМО] Болезнь Киёмори

**Статус:** вымышленный тестовый эпизод, не историческое сведение.

**Что случилось.** В синтетическом фрагменте Киёмори не является ко двору из-за
недомогания, а окружающие беспокоятся о тяжести болезни. Дата и место в данных
не указаны, поэтому карточка их не добавляет.

**Почему это интересно.** Пример показывает ограниченный пересказ короткого
японского фрагмента: ИИ сохраняет неопределённость вместо догадки о времени,
месте или диагнозе.

**Фрагмент.** «平清盛は所労により参内せず。人々は病の重さを案じた。»

**Источник.** Синтетический файл `玉葉/772049_0000002.txt`, классификация
`contemporary_diary` / `historical`, страница 2, chunk
`ch_9944270a0fca336332309762`. Текст не является цитатой из «Гёкуё».
